Database e SQL

Come organizzare, interrogare e collegare enormi moli di dati. Dai database relazionali al mondo dei grafi e reti complesse.

1. Cos'è un Database?

Un Database (Banca Dati) è una collezione organizzata di dati, strutturata in modo da poter essere facilmente accessibile, gestita e aggiornata. Mentre un semplice file di testo o un foglio di calcolo va bene per pochi dati, quando le informazioni diventano milioni, abbiamo bisogno di uno strumento specializzato chiamato DBMS (Database Management System).

Database Relazionali (RDBMS)

Nei database relazionali, i dati sono organizzati in Tabelle (che assomigliano a fogli di calcolo). Ogni tabella ha colonne (chiamate campi o attributi) e righe (chiamate record). Le tabelle possono essere collegate tra loro (messe in "relazione") attraverso campi in comune chiamati Chiavi Esterne (Foreign Keys).

2. Il Linguaggio SQL

SQL (Structured Query Language) è il linguaggio standard per comunicare con i database relazionali. Con SQL possiamo creare tabelle, inserire dati, modificarli e soprattutto interrogarli.

La Query SELECT

Il comando più usato in assoluto è la SELECT, che permette di estrarre (leggere) i dati che ci interessano, filtrandoli e ordinandoli.

SELECT nome, cognome
FROM utenti
WHERE eta > 18
ORDER BY cognome ASC;

3. Approfondimento: I Grafi

Non tutti i dati si adattano bene alle tabelle. Immagina un social network: come rappresenti le amicizie tra milioni di utenti? O come calcoli il percorso più veloce tra due città su una mappa? Qui entrano in gioco i Grafi, una struttura dati fondamentale in informatica che descrive un insieme di elementi e le loro reciproche connessioni. Su questa struttura si basano i Graph Database (come Neo4j).

Componenti di un Grafo

  • Nodi (o Vertici): Rappresentano le entità. In un social network sarebbero le persone; in una mappa sarebbero le città.
  • Archi (o Lati/Edges): Rappresentano le relazioni tra le entità. Sarebbero le "amicizie" o le "strade".

I grafi possono essere Orientati (le frecce hanno un verso, es. "Mario segue Luigi" su Twitter) o Non Orientati (la relazione è bidirezionale e reciproca, es. "Mario e Luigi sono amici" su Facebook). Un grafo è Connesso se esiste un percorso (una sequenza di archi) tra ogni coppia di nodi.

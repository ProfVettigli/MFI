Semaforo con Arduino

Costruisci il tuo primo circuito di automazione: controlla tre LED con Arduino simulando il ciclo semaforico e scopri il PWM per regolare la luminosità.

Cosa Serve: Componenti e Schema

Un semaforo Arduino è uno dei primi progetti che impara chi inizia con l'elettronica. È semplice ma insegna concetti fondamentali: programmazione sequenziale, temporizzazione, e controllo di più output contemporaneamente.

Componenti Necessari

Componente Quantità Descrizione
Arduino Uno 1 Microcontrollore principale
LED Rosso 1 LED 5mm (stop)
LED Giallo 1 LED 5mm (attenzione)
LED Verde 1 LED 5mm (via libera)
Resistori 3 220 Ohm (proteggono i LED)
Cavetti ~10 Collegamento del circuito
Breadboard 1 Basetta per prototipi senza saldature

Schema Circuito

Ogni LED ha due connessioni: l'anodo (gamba lunga, positivo) va al pin di Arduino attraverso una resistenza. Il catodo (gamba corta, negativo) va a GND (massa).

Nota importante: Ogni LED ha un limite di corrente (ca. 20 mA). La resistenza 220 Ohm limita questa corrente proteggendo sia il LED che il pin di Arduino.

Codice Arduino per il Semaforo

Ecco il codice C++ che fa lampeggiare il semaforo con il ciclo: Rosso 5 sec → Giallo 2 sec → Verde 5 sec.

const int RED = 8;   //Pin 8
const int YELLOW = 9; //Pin 9
const int GREEN = 10; //Pin 10

void setup() {
  pinMode(RED, OUTPUT);
  pinMode(YELLOW, OUTPUT);
  pinMode(GREEN, OUTPUT);
}

void loop() {
  //Rosso: STOP
  digitalWrite(RED, HIGH);
  digitalWrite(YELLOW, LOW);
  digitalWrite(GREEN, LOW);
  delay(5000);

  //Giallo: ATTENZIONE
  digitalWrite(RED, LOW);
  digitalWrite(YELLOW, HIGH);
  digitalWrite(GREEN, LOW);
  delay(2000);

  //Verde: VIA LIBERA
  digitalWrite(RED, LOW);
  digitalWrite(YELLOW, LOW);
  digitalWrite(GREEN, HIGH);
  delay(5000);
}

Nota: delay(5000) blocca il programma per 5000 millisecondi (5 secondi). È semplice ma funziona bene per questa applicazione.

PWM: Pulse Width Modulation

Se vuoi controllare non solo l'accensione/spegnimento (HIGH/LOW) ma anche la luminosità di un LED, usi il PWM (Pulse Width Modulation). Arduino ha 6 pin PWM: 3, 5, 6, 9, 10, 11.

Con PWM accendi e spegni il LED molto velocemente (500+ volte al secondo). Controllando quanto tempo rimane acceso vs. spento, percepisci una variazione di luminosità. Ecco un esempio:

analogWrite(pin, brightness);
//brightness: 0 (spento) ... 255 (piena luminosità)

void setup() {
  pinMode(3, OUTPUT);
}

void loop() {
  //Incrementa la luminosità da 0 a 255
  for (int i = 0; i <= 255; i++) {
    analogWrite(3, i);
    delay(10);
  }
  //Decrementa da 255 a 0
  for (int i = 255; i >= 0; i--) {
    analogWrite(3, i);
    delay(10);
  }
}

Caso d'uso: Con PWM puoi regolare la luminosità di un LED, la velocità di un motore, o il tono di un buzzer. È la base di molti progetti Arduino avanzati.

Variante Pedonale: Semaforo con Pulsante

Un semaforo realistico ha un pulsante per i pedoni. Ecco come modificare il codice per attendere il pulsante prima di cambiare da Rosso a Verde:

const int RED = 8;
const int GREEN = 10;
const int BUTTON = 2; //Pulsante su pin 2

void setup() {
  pinMode(RED, OUTPUT);
  pinMode(GREEN, OUTPUT);
  pinMode(BUTTON, INPUT);
}

void loop() {
  digitalWrite(RED, HIGH);   //Rosso
  
  //Aspetta che il pedone premi il pulsante
  while (digitalRead(BUTTON) == LOW) {
    delay(50);
  }
  delay(500); //Debouncing
  
  digitalWrite(RED, LOW);
  digitalWrite(GREEN, HIGH);  //Verde
  delay(5000);
  digitalWrite(GREEN, LOW);
}

Con questa modifica, il semaforo rimane rosso finché il pedone non preme il pulsante. È un comportamento più realistico e utile.

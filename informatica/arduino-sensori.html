Sensori Ambientali

Dal mondo analogico al digitale: come Arduino legge temperature, umidità e luminosità attraverso convertitori ADC.

Tipi di Sensori

I sensori trasformano grandezze fisiche in segnali elettrici. Arduino può leggerli e interpretarli per reagire all'ambiente.

Sensore di Temperatura (DHT22/LM35)

Misura la temperatura ambientale in Celsius. Fondamentale per meteo-stazioni e sistemi di controllo clima.

Sensore di Umidità (DHT22)

Rileva l'umidità relativa dell'aria in percentuale. Spesso integrato con il sensore di temperatura.

Sensore di Luminosità (LDR/BH1750)

Misura l'intensità della luce. Usato in sistemi di illuminazione automatica.

Sensore di Pressione

Rileva la pressione atmosferica. Utile per previsioni meteo e altimetri.

ADC: Analogico ↔ Digitale

I sensori spesso forniscono segnali analogici (una tensione continua tra 0V e 5V). Arduino ha una CPU digitale che capisce solo 0 e 1, quindi occorre un convertitore ADC (Analog-to-Digital Converter) per tradurre.

Fatto: Arduino UNO ha un ADC a 10 bit, che significa può distinguere 2^10 = 1024 livelli diversi. Una tensione tra 0V e 5V viene mappata a un numero tra 0 e 1023.

Formula di Conversione

Tensione (V) = (Valore ADC / 1023) × 5

Se l'ADC legge 512, la tensione è (512 / 1023) × 5 ≈ 2.5V

Conversione Celsius e Lettura Sensore

Un sensore LM35 fornisce una tensione proporzionale alla temperatura: 10mV per ogni grado Celsius.

Formula per LM35

Temperatura (°C) = (Tensione in V) × 100

Se la tensione è 2.5V, la temperatura è 2.5 × 100 = 250°C (troppo calda!).

Codice per LM35

const int sensorPin = A0; void setup() { Serial.begin(9600); } void loop() { int adcValue = analogRead(sensorPin); float voltage = (adcValue / 1023.0) * 5.0; float tempC = voltage * 100; Serial.print("Temperatura: "); Serial.print(tempC); Serial.println(" C"); delay(1000); }

Logging Dati con Serial.print

Arduino comunica con il computer (e con noi) attraverso la porta seriale. La funzione Serial.print() invia dati al Monitor Seriale, permettendo di loggare letture sensori in tempo reale.

Funzioni di Output

Serial.print(data)

Stampa il dato senza andare a capo

Serial.println(data)

Stampa il dato e va a capo

Serial.begin(9600)

Inizializza la comunicazione seriale alla velocità di 9600 baud

Esempio di Logging

void setup() { Serial.begin(9600); } void loop() { int light = analogRead(A0); int temp = analogRead(A1); Serial.print("Luce: "); Serial.print(light); Serial.print(" | Temp: "); Serial.println(temp); delay(1000); }

Nel Monitor Seriale vedrai uscite come: "Luce: 512 | Temp: 768"

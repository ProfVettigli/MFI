Formule di Risoluzione

Equazioni Elementari
$$\sin x = k \Rightarrow x = \arcsin(k) + 2\pi n, \quad x = \pi - \arcsin(k) + 2\pi n$$
$$\cos x = k \Rightarrow x = \pm\arccos(k) + 2\pi n$$
$$\tan x = k \Rightarrow x = \arctan(k) + \pi n$$
Forma Generale

Per ogni soluzione principale α, la forma generale include tutti gli angoli coterminali:

$$x = \alpha + 2\pi n, \quad n \in \mathbb{Z}$$

Disequazioni Goniometriche

Le disequazioni si risolvono usando il cerchio unitario: trova gli archi dove la funzione soddisfa la condizione.

  • sin(x) > k: archi dove il seno è sopra il valore k
  • cos(x) < k: archi dove il coseno è a sinistra del valore k
  • tan(x) ≥ k: intervalli dove la tangente supera il valore k (escludendo asintoti)
Metodo di Risoluzione
  1. Disegna il cerchio unitario
  2. Traccia la retta y = k per sin(x) o x = k per cos(x)
  3. Identifica i punti di intersezione (soluzioni dell'equazione associata)
  4. Seleziona gli archi che soddisfano la disuguaglianza
  5. Scrivi la soluzione in forma di intervalli

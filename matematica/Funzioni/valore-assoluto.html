Funzione Valore Assoluto

La funzione che "positivizza" tutto: proprietà e trasformazioni geometriche.

1. Cos'è il Valore Assoluto?

Il valore assoluto di un numero \(x\), indicato \(|x|\), è la sua distanza dallo zero sulla retta numerica. Sempre non-negativo:

$$|x| = \begin{cases} x & \text{se } x \geq 0 \\ -x & \text{se } x < 0 \end{cases}$$

Esempi: \(|5| = 5\), \(|-5| = 5\), \(|0| = 0\). Geomtricamente: \(|x|\) è la distanza da \(x\) all'origine.

2. Proprietà Fondamentali

  • \(|x| \geq 0\) per ogni \(x \in \mathbb{R}\).
  • \(|x| = 0 \Leftrightarrow x = 0\).
  • \(|x| = |-x|\) (simmetria rispetto all'origine).
  • \(|xy| = |x| \cdot |y|\) (proprietà moltiplicativa).
  • \(|x + y| \leq |x| + |y|\) (disuguaglianza triangolare).
  • \(||x| - |y|| \leq |x - y|\).

4. Grafici Comunemente Usati

Alcuni grafici classici che combinano il valore assoluto:

  • \(y = |x|\) — forma a "V", vertice in origine, inclinazione 1.
  • \(y = -|x|\) — forma rovesciata a "V", massimo in origine.
  • \(y = ||x| - 1|\) — due "V" affiancate, rappresenta la distanza da \(\pm 1\).
  • \(y = |x - 2| + 3\) — traslazione: spostamento a destra di 2 e in alto di 3.
  • \(y = 2|x| - 1\) — "V" più stretto, riflesso verso il basso.

5. Applicazioni nel Mondo Reale

  • Distanza: La distanza tra due numeri \(a\) e \(b\) è \(|a - b|\).
  • Errore di misura: Se misuriamo un valore \(x\) con errore \(\epsilon\), il valore reale è in \(|x - x_{\text{reale}}| \leq \epsilon\).
  • Moduli di elasticità: Resistenza dei materiali alla deformazione.
  • Controllo della qualità: Verificare se un componente rientra nelle tolleranze \(\pm\) range.
